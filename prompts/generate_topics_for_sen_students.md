Сформуй календарно-тематичне планування з інформатики для **спеціального класу** на навчальний рік.

### 1. Джерело інформації

Використовуй підручник, завантажений у цей проєкт, як **основне джерело інформації**.

Теми уроків, послідовність матеріалу та сторінки домашніх завдань мають відповідати підручнику. Не використовуй інші підручники як основне джерело.

### 2. Кількість уроків

- І семестр — рівно 30 уроків.
- ІІ семестр — рівно 38 уроків.
- Загалом — 68 уроків.

Теми повинні бути логічно розподілені між семестрами.

### 3. Особливості учнів

Це діти з порушеннями інтелектуального розвитку, тому планування має бути адаптованим до їхніх можливостей.

Вимоги:

- Прості та зрозумілі назви уроків.
- Поступове опрацювання матеріалу.
- Більше повторення та закріплення.
- Прості практичні завдання.
- Не перевантажувати учнів складними поняттями.
- Ураховувати повільніший темп засвоєння матеріалу.

### 4. Домашні завдання

Домашні завдання мають бути дуже простими, короткими та доступними для виконання за потреби з допомогою батьків.

Можливі варіанти:

- Прочитати або переглянути відповідні сторінки підручника.
- Розглянути малюнки та назвати зображені предмети.
- Назвати 2–3 приклади за темою.
- Дати коротку усну відповідь.
- Записати одне слово, визначення або коротке речення в зошит.
- Виконати нескладне завдання з підручника.
- Намалювати простий предмет або схему, якщо це доцільно.
- Повторити вивчені поняття.

Не задавай складних письмових робіт, великих текстів або завдань, які потребують спеціальних комп’ютерних навичок.

**Важливо:**
- Не використовуй формулювання «разом із дорослим», «з допомогою батьків», «вдома» безпосередньо в тексті домашнього завдання.
- Не задавай просте розфарбовування малюнків як домашнє завдання.
- Записувати слова, короткі речення та прості відповіді в зошит дозволено.
- За можливості вказуй точні сторінки підручника.

### 5. Тематичне оцінювання

Наприкінці **кожної теми** обов’язково додавай окремий урок:

`topic: Тематичне оцінювання`

Для нього також мають бути `homework` і `safety_topic`.

Тематичне оцінювання входить у загальну кількість уроків семестру, а не додається понад неї.

### 6. Інструктаж із безпеки життєдіяльності

Поле `safety_topic` обов’язкове для **кожного уроку**, зокрема для тематичного оцінювання.

Для найпершого уроку І семестру:

`safety_topic: Первинний інструктаж з БЖД.`

Для всіх наступних уроків обох семестрів, без винятків:

`safety_topic: Інструктаж з БЖД.`

Не використовуй інших формулювань і не пропускай це поле.

### 7. Навчальні періоди

Для першого семестру:

```yaml
terms:
  - start: 2026-09-01
    end: 2026-10-25
  - start: 2026-11-02
    end: 2026-12-23
```

Для другого семестру:

```yaml
terms:
  - start: 2027-01-11
    end: 2027-03-21
  - start: 2027-03-29
    end: 2027-05-28
```

Дати початку та завершення періодів включні. Канікули не входять до навчальних періодів.

### 8. Формат YAML

Створи справжній `.yml` файл із такою структурою:

```yaml
semesters:
  - terms:
      - start: 2026-09-01
        end: 2026-10-25
      - start: 2026-11-02
        end: 2026-12-23
    topics:
      - title: Інформація
        lessons:
          - topic: Правила роботи за комп'ютером
            homework: с. 7-11, повторити правила безпечної роботи
            safety_topic: Первинний інструктаж з БЖД.
          - topic: Що таке інформація
            homework: с. 12-15, назвати 2 приклади інформації
            safety_topic: Інструктаж з БЖД.
          - topic: Тематичне оцінювання
            homework: Повторити вивчені поняття
            safety_topic: Інструктаж з БЖД.

  - terms:
      - start: 2027-01-11
        end: 2027-03-21
      - start: 2027-03-29
        end: 2027-05-28
    topics:
      - title: Об'єкти та моделі
        lessons:
          - topic: Об'єкти навколишнього світу
            homework: с. 87-91, назвати 3 об'єкти
            safety_topic: Інструктаж з БЖД.
```

Це лише приклад структури, а не повний перелік уроків.

**Вимоги до структури:**
- `semesters` — масив рівно з двох елементів.
- Кожен семестр має поля `terms` та `topics`.
- `topics` — масив тематичних розділів.
- Кожна тема має `title` та `lessons`.
- Кожен урок має рівно три поля: `topic`, `homework`, `safety_topic`.
- Не додавай поле `number`, `semester`, `lesson_number` чи інші додаткові поля.
- Не використовуй YAML anchors, aliases або посилання між елементами.

### 9. Перевірка перед завершенням

Обов’язково програмно перевір готовий YAML:

1. Файл коректно парситься.
2. `semesters` містить рівно 2 елементи.
3. І семестр містить рівно 30 уроків.
4. ІІ семестр містить рівно 38 уроків.
5. Останній урок кожної теми — «Тематичне оцінювання».
6. Кожен урок містить усі три обов’язкові поля.
7. Перший урок має первинний інструктаж, усі інші — звичайний.
8. Дати навчальних періодів відповідають указаним.
9. Домашні завдання відповідають темам і доступні учням з особливими освітніми потребами.
10. Посилання на сторінки підручника відповідають його змісту.

### 10. Результат

Створи готовий `.yml` файл для завантаження.

Не обмежуйся виведенням YAML у чаті — мені потрібен саме файл.

У відповіді коротко вкажи кількість уроків, кількість тематичних оцінювань для кожного семестру та надай посилання для завантаження файлу.
